# BABLOOH GAMES

Telegram Mini App. Новая версия на React — в папке [`web/`](web/).

## Быстрый старт (React)

```bash
cd web
npm install
npm run dev
```

Сборка: `npm run build` → `web/dist/`

## Что переписано

- Хаб (меню + рейтинг) на React + Framer Motion
- **BABLOOH Ninja** — React, canvas, векторные SVG-персонажи
- Flappy / Eggs / Doodle пока как HTML в iframe

Старые корневые `*.html` оставлены для совместимости.
