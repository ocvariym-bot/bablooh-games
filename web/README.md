# BABLOOH GAMES (React)

Telegram Mini App на React + Vite + Framer Motion.

## Запуск

```bash
cd web
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Папка `dist/` — готовый статический сайт для хостинга (GitHub Pages / Netlify).

## Что внутри

- React-хаб с анимированным меню и рейтингом
- **BABLOOH Ninja** на React: canvas-геймплей + векторные SVG-персонажи
- Flappy / Eggs / Doodle пока открываются как HTML в iframe (`public/games/`)

## Персонажи

Векторные SVG-компоненты: `src/components/characters/`
- парень (V-neck)
- девушка (худи + веснушки)
- голова Bablooh (густые брови)
- sleep / game-over
- бомба

## BABLOOH MATCH

Новая игра «три в ряд»: свайпните или выберите два соседних лица. 4 в ряд создают бомбу 3×3, 5 — ракету по строке; чтобы активировать бонус, включите его в комбинацию. Доступны два молотка и два перемешивания за партию, 30 ходов. Рекорд хранится локально; после партии результат отправляется в общий рейтинг под gameId `match`, если игра запущена в Telegram. Серверная функция submit-score и ограничения базы данных должны разрешать этот gameId; серверный код не входит в архив, поэтому его совместимость необходимо проверить на стороне Supabase. Портреты подготовлены из предоставленных фотографий и находятся в `public/games/match/`.

Анимации BABLOOH MATCH реализованы с Framer Motion: обмен и возврат карточек, подсветка и исчезновение комбинаций, падение новых карточек, взрывы, молоток и перемешивание. Настройка сокращения движения в системе учитывается.
